# GioSer · Web de la agencia

Web de **GioSer, agencia publicitaria en Lima**. HTML y CSS en un solo archivo (`index.html`), sin librerías. Las imágenes van en WebP y cargan al llegar a ellas.

**Demo en vivo:** se activa con GitHub Pages (Settings → Pages → Deploy from a branch → `main` / root).

## Antes de publicar
Busca `[por confirmar]` en `index.html` y reemplaza: correo, WhatsApp, distrito, horario y redes.
Confirma con cada cliente que su trabajo se puede mostrar en el portafolio.
